## Failures

P5/P6 작성 중의 최초 타입 오류는 소유자에게 전달했으며 최종 lint/build는 통과했다. P4 기존 I-P1은 하네스 queue delete와 fingerprint가 경합했다. 임시 emitted test 계측에서 실패 직전/직후 유일한 차이가 intake queue 행수 1→0이었다. 원본/P4 파일 수정 없이 ASK6309981329·NOTE6310033957로 전달했다.

별도 진단 실행은 22건 중 19 PASS·3 FAIL(두 하위 시험+부모 집계). I-P1 외에 cookie 재시도 전체 Set-Cookie 문자열이 Expires 1초 차로 실패했다. ASK6310034741로 시험 결정성 재검증을 요청했다. fixture cookie는 로그에서 마스킹했다. 이 두 P4 시험 문제를 조립/실DB smoke 성공으로 숨기지 않는다.

## Reproducibility

`.cache/base-s3/run-check.py`가 실제 command/cwd/exit/seconds와 stdout/stderr를 기록한다. emitted 검증은 `tsconfig.json`→`prepare-tests.py`→`suite.py`이며 기본 runner와 별개다. `P4_TEST_LOADER`는 해당 cache loader를 가리킨다. 초기 cache 설정 오류 뒤 수정한 최종 실행만 위 수치에 사용했다. 소유 파일 목록은 artifacts.json의 13개이며 동시 담당의 변경은 포함하지 않는다.

호스트 후속: exact manifest 기준 npm install·lock 재생성, 표준 npm test, P4 시험 동기화/시간 비교 검토, 전체 Vite/Docker/deploy. P5 production reactions/HTTP/stream·worker/scheduler 및 직접 node HOST binding·운영 secret mount는 미검증이다.
