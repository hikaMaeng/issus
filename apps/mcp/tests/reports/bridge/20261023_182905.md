TS2352: 인덱스 시그니처를 단언하던 fromEntries 출력을 도구 키 10개의 리터럴과 generic result 함수로 바꾸고 `satisfies Record<ToolName,z.ZodType>`로 누락을 검사한다. `as unknown as`는 사용하지 않았다.

## Failures
두 TypeScript 오류는 해소되었다. esbuild 자식 프로세스 생성은 샌드박스 EPERM으로 차단됐다. 허용된 호스트 재빌드 항목이며 우회하지 않았다. --help는 지원 옵션이 아니므로 exit1을 예상 거절로 기록했다.

native-smoke는 호스트가 18:21:58에 생성한 기존 dist/index.js(1,268,402 bytes)의 실제 OS stdio만 확인했다. synthetic env를 주입해 profile/실제 자격증명 파일을 읽지 않았고, initialize/tools/list만 호출해 HTTP·업무 상태 쓰기를 발생시키지 않았다. 수정된 소스의 번들 검증은 아니다.
