## Failures

원 실패는 §7이 허용한 댓글 POST202를 시험이 곧바로201과 비교한 것이다. 서버 계약 변경 없이 관측 경계를 수정했다. 실DB에서 동기 완료 의무 명령의202는 관측하지 않았다. 그런 응답은 새 헬퍼가 설계 위반으로 실패시키며 성공으로 완화하지 않는다.

표준 npm 시험은 sandbox spawn EPERM으로 호스트 재실행이 필요하다. 첫 보조 실행의 Windows 절대 loader 경로 오류는 file URI로 고쳤고 이전 로그를 보존했다. 예비 deliveries53/53은 P8을 제외한 수치이며 최종54건과 구분한다. 배포·브라우저·외부 Monitor 깨우기는 이번 범위가 아니다.
