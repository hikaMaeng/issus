## 선행 조건
- U1 공통 export 동결·RELEASE6314940213, Q1/Q2 core REPORT6314607727, U2 최종 REPORT와 entry/app의 U2/U3 경로 조립. U3 Compact export는 pages/compact/index.tsx; 조립 ASK6315157046.
- production dist와 extra migration0004까지 build되어야 한다. root manifest·compose·barrel은 U3가 수정하지 않는다. 동작 결함을 fixture 성공 payload로 대체하지 않는다.
- `p9-host.mjs`는 P8 fixture regex와 기존12를 보존하기 위해 고유 issus_test_p8_<suffix>·issus_test_p8_b_<suffix>와 p9_browser_<suffix>_ queue를 쓴다. API repo→실제 schema를 대조하며 제품 schema·기존 namespace를 쓰지 않는다.
- alias A/B·OWNER·board·NOENV 보존 projection·이전 COMPACT는 기존 fixture.mjs가 만든다. bootstrap은 메모리/환경 전달만 사용한다. secret 파일·인증 trace·원 packetToken을 읽거나 기록하지 않는다.
- 세션 TTL48h의 일회성 fixture에서만 Clock을 주입한다. P9-19는 +24h+1s로 실제 packet TTL24h의410을 받고 즉시 복귀한다. P9-22는 실제 admission 뒤 Clock+60s로 worker DUE 재검사422를 받는다. TTL/제품 코드/성공 응답/운영DB 시간을 수정하지 않는다.
- `--standard`는 root test:browser의 ISSUS_TEST_CLOCK_FILE 전달과 Clock 사용 browser 파일 직렬 실행이 필요하다(ASK6315588535). 직접 명령은 자체 --test-concurrency=1로 같은 네 파일을 실행한다. Clock 없는 환경의 해당 필수 시험은 skip하지 않고 실패한다.

```powershell
$env:ISSUS_TEST_SERVER_URL='http://127.0.0.1:18141'
```

오케스트레이터가 18140에 별도 격리 fixture와 Clock/직렬 실행을 공급한 경우의 정본 명령은 아래다. 제품18140에 시험 fixture를 넣지 않는다. 명령 자체가 fixture를 생성하지 않는다.
