# 개요

저장소/이슈 목록·상세·inbox와 명시적 댓글/ACK/close를 제공한다. 경로와 고정 locator는 [제약](constraints.md), 전체 기능 범위는 [루트 개요](../../../../../docs/overview.md)다. Markdown은 실행하지 않고 pre로 표시한다.

U1은 /login·/sessions·/repos·/repos/:owner/:repo/issues·/owners/:owner/aliases를 추가/확장한다. Q1 registry는 본문 ROSTER·현재 principal·등록 레지스트리·최근 검사/등록 응답을 구분한다. Q2는 OWNER/참여 별칭/검색/정렬을 서버에서 조회하고 전 페이지 수집 후 작업 STATE/제목순을 적용한다. 신규 board/개설/편집/COMPACT 화면은 U2/U3 export의 조립을 기다린다.
