# 슬롯 연결

composer는 body/fields/structured/deferred, issue-form은 title/body/fields/base, compact는 body/author/purpose/previousReview만 등록한다. 슬롯 이름은 기능명으로 시작하고 같은 페이지의 다른 폼과 중복하지 않는다.

편집 baseline은 body와 함께 복원해 원래 If-Match를 유지한다. COMPACT의 이전 대조 id는 기록으로만 복원하고 패킷 준비·원문 열기·선택은 다시 수행한다. 복원 자체로 요청·검사·게시를 실행하지 않는다.
