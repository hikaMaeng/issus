3. U-C2/I-06: 실제 issue OWNER packet→P4 댓글 게시, 3건 표본·compactedBy·unknown key·다른TYPE metadata·첫/후속 RE·marker·through·2001자.
4. I-06: snapshot 뒤 새 댓글·본문 revision·TTL·OWNER 변경·packet hash 변경 거부. preflight 읽기 후 DB 차분0.
5. append/queue 실패 주입 후 comment·pointer·revision·segment·facts·command_result 롤백. prepare append 실패도 due·packet·command_result 롤백 후 동일 key 재시도 성공. 다음 packet에 이전 COMPACT+새 구간만, 페이지 사이 새 COMPACT·댓글이 생겨도 기존 커서 경계/원문/남은 댓글 불변, sinceCompact=false는 전구간.
6. tail0/no control204·control-only packet·구간 밖 legacy/ackState/HOLD/CLAIM/handoff 부록, prepare idempotency·사유 due 기록.
7. domain/app npm test 및 lint, 서버 bundle. 표준 실행이 환경 EPERM이면 실제 오류와 대체 명령을 분리 기록한다.
